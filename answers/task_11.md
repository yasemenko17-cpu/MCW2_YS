# Завдання 11. Простори імен і контрольні групи (легке)

**Умова.** Поясніть своїми словами, чим простори імен (namespaces) відрізняються від контрольних груп (cgroups) і на яке запитання відповідає кожен із цих механізмів. Наведіть по одному прикладу з Docker для кожного і скажіть, що станеться, якщо для контейнера не задано ліміт пам'яті.

Напишіть відповідь своїми словами під рядком нижче (5–8 речень).

Відповідь:

Простори імен (namespaces) ізолюють системні ресурси контейнера (процеси, мережу, точки монтування) від хоста та інших контейнерів, відповідаючи на запитання «що процес може бачити?». Контрольні групи (cgroups) обмежують і контролюють використання апаратних ресурсів (CPU, пам'ять, I/O), відповідаючи на запитання «скільки ресурсів процес може споживати?». Прикладом namespaces у Docker є PID namespace, що ізолює ідентифікатори процесів, а прикладом cgroups — обмеження пам'яті через параметр memory limit. Якщо для контейнера не задано ліміт пам'яті, він може споживати весь вільний обсяг оперативної пам'яті вузла. У разі вичерпання загальної пам'яті хоста спрацює механізм ядра Linux OOM Killer (Out-Of-Memory Killer), який примусово завершить процес контейнера для захисту системи від падіння.
